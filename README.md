# Beige & Dark Teal

A Chrome theme with a pastel beige toolbar and active tab, dark teal background tabs, and a white address bar and New Tab page.

## Installation

1. Download this repository using **Code → Download ZIP**, then unzip it.
2. Open Chrome in the profile where you want to use the theme.
3. Go to `chrome://extensions` and enable **Developer mode**.
4. Click **Load unpacked** and select the extracted folder containing `manifest.json`.

## Removal

Go to **Settings → Appearance → Reset to default**.
